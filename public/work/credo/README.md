# Screenshot drop-in for /work/credo-tri-indy-car

Add files here with these exact names and they'll automatically appear on the
case study page (no code changes needed — just redeploy):

- `cover.webp` — hero shot (home screen / race countdown), used on this page and its /work archive card
- `schedule.webp` — race schedule list
- `team.webp` — driver & team profiles
- `track-map.webp` — interactive track map
- `vip.webp` — VIP experiences
- `chat.webp` — fan chat (Stream Chat)
- `qr.webp` — QR code check-in / scanner
- `theming.webp` — side-by-side of two client themes (e.g. CEDO demo vs. JHR) to show off the white-label system

.png or .jpg also work — just update the extension in
`app/work/credo-tri-indy-car/page.tsx` (`SHOTS` array) to match.
